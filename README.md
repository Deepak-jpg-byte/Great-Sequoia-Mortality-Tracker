# Great-Sequoia-Mortality-Tracker
The Giant Sequoia Mortality Tracker is an Excel-based data management project designed to organize, monitor, and analyze mortality records for Giant Sequoia trees. The purpose of this project is to provide a structured and efficient system for maintaining accurate records, improving data accessibility, and supporting informed decision-making through organized data tracking.

This workbook was developed using Microsoft Excel and incorporates data management principles to streamline the collection and organization of mortality information. By maintaining clean, consistent, and well-structured datasets, users can easily review records, identify trends, and generate meaningful insights from the data.

Through this project, I strengthened my skills in data organization, spreadsheet design, formula implementation, and analytical thinking. The tracker demonstrates how Excel can be used beyond basic data entry to create practical solutions for managing real-world datasets.

The project reflects my interest in data management and process improvement by transforming raw information into a reliable and user-friendly tracking system. It showcases my ability to build tools that improve efficiency, support reporting needs, and enhance the overall quality of data-driven workflows.

Tools Used: Microsoft Excel
Skills Demonstrated: Data Management, Data Analysis, Spreadsheet Design, Reporting, and Process Improvement.
